# Quickshell виджеты (аналог EWW конфига)

## Установка

1. Установите Quickshell:
```bash
# Для Arch Linux
yay -S quickshell-git

# Или из AUR
paru -S quickshell-git
```

2. Скопируйте файлы в директорию Quickshell:
```bash
mkdir -p ~/.config/quickshell
cp -r quickshell_widgets/* ~/.config/quickshell/
```

3. Запустите:
```bash
qs shell
```

## Структура файлов

- `main.qml` - главный файл с компоновкой виджетов
- `widgets.ts` - логика всех виджетов (TypeScript/JSX)
- `style.css` - стили (аналогично CSS в EWW)

## Виджеты

### 1. Часы и дата (`Clock`, `DateWidget`)
- Время в формате HH:MM:SS с обновлением каждую секунду
- Дата в формате DD.MM.YYYY
- День недели на русском языке

### 2. Монитор CPU/RAM (`CpuMonitor`)
- Текущая загрузка CPU в процентах
- Текущее использование RAM в процентах
- Исторический график загрузки CPU (50 точек)

### 3. Громкость (`VolumeControl`)
- Слайдер громкости
- Кнопка Mute/Unmute
- Индикатор текущего уровня громкости
- Управление через pactl (PulseAudio/PipeWire)

### 4. Визуализатор CAVA (`CavaVisualizer`)
- 51 полоса частот
- Обновление ~20 FPS
- Градиентная раскраска

### 5. Музыкальный плеер (`PlayerWidget`)
- Обложка альбома (автоматическая загрузка)
- Название трека, исполнитель, альбом
- Прогресс-бар с перемоткой
- Кнопки управления: Play/Pause, Next, Previous
- Переключатель Shuffle и Loop (None/Track/Playlist)
- Автоматическое обновление информации о треке
- Поддержка всех MPRIS-совместимых плееров (Spotify, Firefox, VLC и др.)

## Требования

- **pactl** - для управления громкостью (pulseaudio-utils или pipewire)
- **cava** - для визуализатора аудио (`sudo pacman -S cava`)
- **playerctl** - для управления музыкальным плеером (`sudo pacman -S playerctl`)

## Настройка стилей

Отредактируйте `style.css` для изменения:
- Цветов и градиентов
- Размеров шрифтов
- Отступов и скруглений
- Прозрачности фона

## Примечания

- Виджет "Топ приложений" требует кастомной реализации (нет встроенного API для получения списка процессов)
- CAVA должна быть настроена на вывод в raw формате
- Все виджеты используют реактивную систему Quickshell для автоматического обновления
